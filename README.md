# ⚡ Volt-Spec (볼트-스펙)
> **RAG 기반 양산형 전기차 및 고전압 배터리 기술 분석 지식 서비스 (AI 코어 프로젝트 2회차)**

`Volt-Spec`은 국내외 양산형 전기차 **100종**의 공식 제원 메타데이터(`ev_meta`)와 **한국어 위키백과** 기술 문서(`ev_wiki`)를 결합하여, **환각(Hallucination) 없이 명확한 근거(`[근거 N]`)와 원문 출처**를 함께 제시하는 **LangGraph + ChromaDB + Streamlit** 기반 도메인 지식 서비스입니다.

---

## 📌 1. 왜 전기차·배터리 도메인에서 RAG가 필수적인가?

전기차 및 고전압 배터리 도메인은 **시스템 전압 규격(400V vs 800V), 배터리 셀 화학 조성(NCM 삼원계 vs LFP 리튬인산철), 배터리 용량(kWh), 급속 충전 소요 시간(10→80%), 전용 플랫폼(E-GMP, J1, PPE, MEB, Ultium 등)**과 같이 정밀한 엔지니어링 수치가 핵심입니다.
- **근거 없이 답할 때의 문제점**: 순수 LLM의 사전학습 기억에만 의존하면 연식·트림 간 수치가 뒤섞이거나, 존재하지 않는 미출시 차량 사양을 그럴듯하게 지어내는 환각이 발생하며, 고전압 배터리·충전 규격에 관한 잘못된 정보는 안전상 위험을 초래할 수 있습니다.
- **Volt-Spec의 해결 방식**: 선택된 차량의 공식 메타데이터(`ev_meta`)와 위키백과 기술 본문(`ev_wiki`)을 병합 검색하여 **오직 검색된 문서에 있는 사실만 `[근거 N]` 번호와 함께 답변**하고, 문서에 없는 내용은 `"제공된 문서에서 확인되지 않습니다"`라고 명확히 안내합니다.

## 🛠️ 3. 전체 기능 설명 (필수 기능 & 심화 기능 구분)

### ✅ 필수 기능 (`F2001` ~ `F2012`)
1. **데이터 준비 및 메타데이터 색인 (`F2001`, `F2002`)**
   - 100종 전기차의 10개 속성을 단일 검색 텍스트로 구성하여 ChromaDB `ev_meta` 컬렉션에 고유 ID(`EV_1`~`EV_100`)로 색인합니다. 재실행 시 덮어쓰기(Upsert)로 중복을 방지하며, 사이드바 상단에 현재 색인 건수를 상시 표시합니다.
2. **LLM 기반 외부 위키 문서 수집 및 청킹 색인 (`F2003` ~ `F2005`, `NF2002`)**
   - **프롬프트 1 (`extract_search_keywords`)**: 차량명과 질문에서 위키백과 기술 검색어 3~5개를 JSON 배열로 추출합니다(차량명 첫 번째 필수 포함).
   - **프롬프트 2 (`filter_and_collect_docs`)**: 위키백과 후보(제목+요약) 중 기술 연관 문서만 선별하고 무관한 문서를 제외합니다(차량 본체 문서는 무조건 포함).
   - **청킹 및 `ev_wiki` 색인 (`chunk_and_index_wiki`)**: 본문을 `1,000자` 크기 / `200자` 중복으로 분할하여 `{ev_id}:{doc_title}:{chunk_index}` ID로 색인합니다. 이미 수집한 검색어는 `data/wiki_cache.json`으로 재수집을 생략합니다.
3. **LangGraph 기반 병합 검색 및 근거 인용 생성 (`F2006` ~ `F2008`)**
   - `StateGraph(RAGState)`로 분리된 `retrieve` 노드와 `generate` 노드가 동작합니다.
   - `ev_meta` 기본 제원 청크(항상 포함)와 `ev_wiki` 유사도 상위 청크(`Top-k=3`)를 병합·중복 제거한 뒤, **프롬프트 3**으로 `[근거 N]`이 포함된 답변을 생성하고 실제 인용된 문서만 하단 `st.expander`에 원문 링크와 함께 표시합니다.
4. **차량별 멀티턴 채팅 · 도메인 특화 기능 · 자연어 조건 탐색 (`F2009` ~ `F2012`)**
   - **차량별 대화 분리 (`F2009`)**: 차량을 바꿔도 이전 대화가 섞이지 않도록 차량 ID별 세션 상태를 분리합니다.
   - **도메인 특화 기능 (`F2010`)**: ① **전기차·배터리 3단 심층 기술 리포트 생성** 및 ② **기술 주장 팩트체크(사실 / 문서 내용과 다름 / 문서에서 확인되지 않음 판정)** 기능을 근거와 함께 제공합니다.
   - **자연어 조건 기반 탐색 (`F2011`)**: *"800V 초급속 충전을 지원하는 현대·기아 전기차"* 등 자연어 조건을 입력하면 `ev_meta` 검색 + LLM 선별 후 카드로 제시하며, 카드의 선택 버튼을 누르면 즉시 해당 차량 대화로 이어집니다.
   - **진행 상태 및 면책 안내 (`F2012`)**: `st.status` 실시간 단계 표시, 키/색인 누락 안내, 고전압 배터리 안전 면책 문구를 상시 노출합니다.

### 🌟 심화 기능 (`F2014`, `F2015`, `F2016`)
- **`F2014` (MMR 다양성 검색 적용)**: 사이드바 설정 패널에서 `유사도 검색(Similarity)`과 `MMR 다양성 검색(fetch_k=10, lambda=0.6)`을 실시간 전환하며 검색된 문맥 차이를 비교할 수 있습니다.
- **`F2015` (RAG 사용 전후 답변 품질 비교)**: 대표 질문 5개에 대해 순수 LLM과 Volt-Spec RAG의 답변을 비교 분석하여 `docs/3_검증결과_및_품질비교.md`에 문서화했습니다.
- **`F2016` (다중 문서 출처 결합 및 구분)**: 내부 정형 제원(`차량 메타데이터`)과 외부 비정형 문서(`한국어 위키백과`)를 결합하고 근거 목록에 출처 종류를 명확히 구분해 표시합니다.

## 🚀 4. 데이터 준비 및 프로젝트 실행 방법

### 1) 환경 변수 설정 (`.env`)
```ini
GMS_KEY=발급받은_SSAFY_GMS_KEY
OPENAI_BASE_URL=https://gms.ssafy.io/gmsapi/api.openai.com/v1/
WIKI_CONTACT=본인_영문_이메일@example.com
```

### 2) 데이터 생성 및 메타데이터 초기 색인 절차
```bash
# 1. 양산형 전기차 100종 JSON 생성 (data/ev_metadata.json)
python src/make_data.py

# 2. ChromaDB 'ev_meta' 컬렉션 100건 임베딩 색인
python src/index_metadata.py
```

### 3) 위키 수집·색인 및 LangGraph RAG 단독 검증 (선택)
```bash
# 아이오닉 5 위키백과 수집·선별·청킹 색인 테스트
python src/collect_and_index_wiki.py

# LangGraph (retrieve -> generate) 파이프라인 단독 테스트
python src/core_rag.py
```

### 4) Streamlit 웹 서비스 실행
```bash
streamlit run app.py
```
