## 4.3 답변과 근거 확인 (F2006 ~ F2008)

| 점검 항목 | 결과 | 확인 근거 및 실행 결과 요약 |
| :--- | :---: | :--- |
| 검색할 근거 수(Top-k)를 설정에서 바꿨을 때 같은 질문의 근거 목록이 어떻게 달라지는지 확인한다. | **통과** | 사이드바 `Top-k` 슬라이더(1~8) 조정 시 병합 문맥 수가 `1(메타) + k(위키)`건으로 즉시 변경됨 |
| LangGraph가 `retrieve`와 `generate` 두 노드로 구성되어 있는지 확인한다. | **통과** | `src/core_rag.py`의 `build_rag_graph()`에서 `retrieve` → `generate` → `END` 2노드 구성 확인 |
| 답변 본문의 근거 번호와 화면에 표시된 근거 목록이 일치하는지 확인한다. | **통과** | `extract_cited_sources()`가 정규식으로 실제 인용 번호만 파싱하여 하단 `st.expander`에 표시 |
| 근거 목록에 항목 메타데이터와 외부 문서가 구분되어 표시되는지 확인한다. | **통과** | `차량 메타데이터`와 `한국어 위키백과` 태그가 각 근거 항목에 구분 표시됨 |
| 문서에 없는 것을 물었을 때 추측하지 않고 확인되지 않는다고 답하는지 확인한다. | **통과** | 2029~2030년 미출시 사양 질문 시 `"제공된 문서에서 확인되지 않습니다"` 응답 확인 |
| 답변에 인용된 근거가 하나도 없을 때 그 사실이 화면에 안내되는지 확인한다. | **통과** | `"ⓘ 답변에 인용된 근거가 없습니다"` 안내 캡션 정상 출력 |

## 4.4 서비스 기능과 화면 확인 (F2009 ~ F2012)

| 점검 항목 | 결과 | 확인 근거 및 실행 결과 요약 |
| :--- | :---: | :--- |
| 항목을 바꿨을 때 이전 대화가 섞이지 않는지 확인한다. | **통과** | `st.session_state.messages_by_ev[ev_id]` 구조로 차량별 대화 이력 완벽 분리 |
| 조건 기반 탐색 결과에 조건과 맞지 않는 항목이 섞이지 않는지 확인한다. | **통과** | 탭 3(`F2011`)에서 `ev_meta` 유사도 검색 후 LLM이 조건 부합 차량만 엄격 선별 및 카드 선택 연동 |
| 도메인 특화 기능의 결과에도 근거가 함께 제시되는지 확인한다. | **통과** | 탭 2(`F2010`)의 '3단 심층 기술 리포트' 및 '기술 주장 팩트체크' 모두 `[근거 N]` 및 출처 목록 표시 |
| 문서 수집과 답변 생성 중 진행 상태가 표시되는지 확인한다. | **통과** | `st.status`로 프롬프트 1·2 수집 현황 및 LangGraph 검색·생성 진행 단계 표시 |
| 색인이 없는 상태와 API 키가 없는 상태로 실행해 안내가 표시되는지 확인한다. | **통과** | `app.py` 상단에서 키 누락 시 `st.error` 안내, `ev_meta` 0건 시 `st.warning` 색인 명령 안내 표시 |
| 위험한 도메인이면 답변에 전문가 조언/취급 설명서를 대신하지 않는다는 안내가 표시되는지 확인한다. | **통과** | 고전압 배터리·차량 안전 면책 안내 문구(`DISCLAIMER_TEXT`) 사이드바 및 하단 상시 표시 |
